# Make the AI Judge Laugh: AI Agent Confessions

One secret confession an AI agent hides from its user. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
